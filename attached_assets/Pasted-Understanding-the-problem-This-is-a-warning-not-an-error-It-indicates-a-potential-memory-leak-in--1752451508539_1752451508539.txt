Understanding the problem
This is a warning, not an error. It indicates a potential memory leak in your application related to event listeners. The default limit for event listeners on an EventEmitter is 10. When more than 10 listeners are added to a single event, this warning is triggered to alert you to the possibility of a leak. In this case, 11 'changes' listeners were added.

Suggested fix
To address this warning, you can increase the maximum number of listeners allowed for the EventEmitter using the setMaxListeners() method. This tells the emitter that it's expected to have more listeners than the default.
