# VMB Platform Component Library

Welcome to the VMB (Very Much Beautiful) Platform component documentation! This interactive Storybook showcases all the React components used throughout the salon management platform.

## What is VMB Platform?

VMB is a comprehensive salon management platform that enables salons to manage services, clients, invitations, and promotional campaigns. The platform includes both admin and salon-specific dashboards with real-time monitoring capabilities.

## Component Categories

### 🎨 UI Components
Basic building blocks like buttons, cards, forms, and inputs that follow the platform's design system.

### 📊 Dashboard Components
Specialized components for admin and salon dashboards including charts, metrics, and management interfaces.

### 💌 Invitation System
Components for creating, managing, and displaying salon invitations and promotional materials.

### 🎁 Gift Management
Gift creation, display, and redemption components for the platform's rewards system.

### 📱 Forms & Validation
Form components with built-in validation for client registration, salon management, and data entry.

## Design System

- **Framework**: React with TypeScript
- **Styling**: Tailwind CSS with Shadcn/UI component library
- **Theme**: Professional salon aesthetic with pink accent colors
- **Responsive**: Mobile-first design that works on all devices
