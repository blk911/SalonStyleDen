Solution for Code Validation and Stability
1. Automated Test Suite
Create automated tests that specifically validate the critical paths we fix
These tests will run after any code change to ensure nothing breaks
Implement tests for:
Sponsor information display
Client/gift relationships
Invitation flows
API endpoint consistency
2. Database Schema Enforcement
Add database constraints to enforce required relationships
For the sponsor field specifically:
Add NOT NULL constraint to sponsorSalonId in clients table
Add foreign key constraint to ensure it always references a valid salon
3. API Contract Enforcement
Create a validation middleware that checks all API responses
Enforce that sponsor information is always included in responses
Return error if critical fields are missing instead of sending incomplete data
4. Core Data Service Layer
Create a single service layer for all database access
Replace direct database access with service calls
Implement validation in the service layer to reject invalid operations
Log attempts to access data without proper fields
5. Version-Locked API Routes
Create versioned API routes (/api/v1/...) for stable endpoints
Never modify existing versioned routes once validated
Create new versions when changes are needed
6. Git Branch Protection
Implement branch protection rules for main/production code
Require passing tests before merging changes
Disallow direct commits to protected branches
7. Feature Flags
Implement feature flags for new functionality
Allow rolling back problematic features without code changes
Control feature availability from admin panel
8. Audit Logging
Add comprehensive audit logging for all data mutations
Track which code paths modify critical data
Quickly identify where data integrity issues originate
9. Integration Testing Environment
Create a staging environment that mirrors production
Run all changes through this environment before deploying
Automated full-system tests run in this environment
